The action control: `primary` (solari-yellow fill, on-yellow text), `secondary` (line-strong outline) and `ghost` (no border).

Use one primary per view. Add `arrow` to buttons that move you on (Buy tickets →). `size="sm"` for the nav. Pass `href` to render a link with the same look.

- Labels are sentence case, two or three words.
- Focus ring is 2px `focus`, offset 2px.
- On a board-tone band, give the secondary button `flap-ink` text so it reads on the housing.
